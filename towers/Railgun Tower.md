# Railgun Tower (Tower 3, Craaghelm)

[Defense Tower (Craaghelm)](Defense%20Tower.md#craaghelm) III · **+250 HP**; final HP is **500 / 700 / 350 / 425** after Castle Tower / Armored Tower / Flame Tower / Tar Tower respectively.

An instant piercing beam, range **36**, nominal cooldown **3 s**. The first enemy takes **50**. Each successive hit applies a **0.7** multiplier (35, then 24.5 before target modifiers). Target multipliers stack: tower-vulnerable 2, ranged armor 0.6, flying 1.15. Blocking geometry or a projectile barrier can cut the beam short.
